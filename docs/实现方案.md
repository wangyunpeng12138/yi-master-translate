# 译境 · 实现方案（沉浸式翻译复刻工程）

> **文档定位**：本方案是译境工程的总设计书。经确认后按第 6 节分阶段实施。
> **功能基线**：以沉浸式翻译商店版 v1.34.4（16 个设置分区 + popup + side-panel + 页面内能力，实测梳理）为准。
> **参考产物**：原版商店编译产物 v1.34.4（逆向依据，不在本仓库内、随仓库分发）。

---

## 1. 目标与范围

### 1.1 目标

用**可读的 TypeScript 源码工程**实现译境：对齐沉浸式翻译（Chrome MV3）的核心功能——设置页 16 分区、工具栏弹窗、侧边栏、内容脚本翻译引擎、后台调度，**功能对等、体验对齐**，但不依赖官网服务、不做付费会员体系。

### 1.2 明确裁剪项（不实现）

| 裁剪项 | 原因 | 处理方式 |
| --- | --- | --- |
| 所有跳转官网的链接/推广位 | 用户要求 | 导航区"价格/使用教程/更新日志/隐私/反馈"、banner"安装手机 APP/翻译文档"、关于页推广位、会员升级链接 → **全部移除** |
| 会员付费体系（Pro/Max 模型分组） | 无付费基础设施 | 服务列表只保留**免费服务 + 自定义 API**两组；原 Pro/Max 分组的 UI 结构保留为可扩展分组但默认隐藏 |
| PDF 在线 viewer（`app.immersivetranslate.com/pdf`） | 强依赖官网 | 改为**本地 PDF.js 方案**（P3 阶段，可选）；前期"翻译本地 PDF"入口保留但标记未实现 |
| EPUB builder/reader（官网页面） | 强依赖官网 | 移除；字幕/EPUB 相关先做**本地字幕文件翻译**（srt/ass/vtt/lrc） |
| Google Drive 云同步 | 三方账号授权复杂 | 只做**本地文件导入/导出**（含术语库复选框） |
| 远程规则同步（"同步最新适配规则"） | 依赖官方 CDN | 内置**精简规则集**（高频站点）+ 开发者设置内本地规则编辑器 |
| 遥测/Sentry（"协助改善用户体验"） | 隐私 | 完全移除，相关 UI 不做 |
| OneAIFW 端侧占位符替换（Beta） | wasm 依赖重、收益有限 | 不实现（进阶设置中该项移除） |
| **无字幕翻译**（视频无原字幕时实时识别） | 依赖官方云端 ASR，本地无法复刻（v1.2 补，评审 3.2-④） | 明确裁剪；字幕能力仅限「已有字幕轨的拦截翻译」 |
| 手机 APP 引导、活动位、Beta 会员文案 | 官网耦合 | 移除 |

### 1.3 保留的核心能力

网页双语翻译引擎、译文样式主题、翻译服务管理（免费 + 自定义 API）、输入框翻译、划词/圈选翻译、鼠标悬停翻译、悬浮球、快捷键体系、视频双语字幕（**仅已有字幕轨的拦截翻译**，无字幕 ASR 不做）、图片/漫画翻译（本地 OCR + canvas hook）、AI 术语库、AI 专家（自定义角色）、AI Write（本地实现简化版）、文本/字幕文件翻译、配置导入导出、本地翻译缓存、右键菜单、开发者设置。

### 2.2 关键机制发现（将沿用或参考）

1. **两级注入链**：guard 常驻做轻量判断 → 动态注入 main。新工程沿用该设计（性能关键）。
2. **配置三层合并**：`default_config.json`（基线默认值，含 `immediateTranslationTextCount: 4999` 等行为参数）+ `rules`（**801 条站点适配规则**，含 selectors / excludeSelectors / injectedCss / 段落阈值 / `advanceMergeConfig` **条件表达式合并**如 `targetLanguage==zh-CN`）+ 用户配置（sync storage）。
   - **版本化覆盖不能简单丢弃**（v1.2 修订，评审 3.2-③）：原版存在 `.add_v.[版本]` 操作符，实际生效值依赖它（如 `pcFloatBall.add_v.[1.30.3]` 将 `enableSidePanel`/`enablePinSidePanel` 覆盖为 false → 悬浮球侧边栏按钮默认隐藏；`inputTrailingTriggerKeyRepeatTimes` 经 3→2→3 链终值为 3）。新工程策略：**在 `defaults.ts` 中一次性 flatten 成生效值**，并在附录 A 标注「来自版本化覆盖」，避免出现「配置写 true、UI 显示关」的偏差。
3. **DNR 用途澄清**（v1.2 修订，评审 3.2-①，逐条核对 32 条规则）：三类用途并存——
   | 类别 | 条数 | 示例 |
   | --- | --- | --- |
   | **翻译 API 请求改头** | 7 | `www2.deepl.com/jsonrpc*`（含移除 cookie）、`api.deepl.com/jsonrpc*`、`transmart.qq.com/api/imt`、`translate.volcengine.com/crx/...`、`dict.youdao.com/jsonapi_s*`、`httpstat.us/429`（连通性测试） |
   | 漫画/图片 CDN 防盗链 | 25 | `i.pximg.net`、`stcdn.manhwato.com`、`*.sinaimg.cn`、`viewer.comic-growl.com` 等 |
   | 本地 Ollama 头豁免 | 2 | `http://*:11434`、`http://*:1234` |
   → 结论：**请求改头靠 DNR 静态规则，不靠 webRequest**；新工程拆分两个规则集文件：`rules-image.json`（防盗链，默认启用）与 `rules-api.json`（第三方通道改头，接 DeepL/腾讯/火山/有道免费通道时按需启用）。
4. **翻译服务层**：103 个服务 ID；AI 服务走「批量增强模式」（`aiBatch.taskSystemPrompt` / `userPrompt: "Translate to {{to}}:\n\n{{text}}"`（含两个换行）、每批段落数 8、字幕批 8、请求节流排队、段落完整性校验 + 局部重试）；术语经 `glossaries` 结构注入提示词（`terms_prompt`），支持按域名生效。**降级链**（v1.2 补，评审 3.3-7）：免费通道失败时 bing → google → 自定义 API 依次降级，P2 验收增加「连续 100 段成功率」指标。
5. **快捷键双轨**：浏览器级命令（Alt+A/W/S/I，`chrome://extensions/shortcuts` 管理）+ 扩展内按键记录（设置页快捷键分区）；manifest `commands` 注册全部命令 ID。
6. **UI 技术栈**：3 个 bundle 均为 React 系压缩产物 + pico.css（classless 框架）+ 自研组件；options 用 hash 路由（`#services/openai-custom` 子路由）。

### 4.3 消息协议（`core/messaging/protocol.ts` 骨架）

```ts
// 请求-响应型
export type Protocol = {
  'config:get':   { req: {}; res: MergedConfig }
  'config:set':   { req: { patch: DeepPartial<UserConfig> }; res: { ok: true } }
  'translate:batch': { req: { texts: string[]; from: string; to: string; service: string; scope: 'page'|'subtitle'|'input'|'selection' }
                      ; res: { texts: string[] } }
  'cache:query':  { req: { hash: string[] }; res: (string | null)[] }
  'ocr:image':    { req: { dataUrl: string }; res: { text: string } }   // → offscreen
  'panel:open':   { req: {}; res: {} }                                    // sidePanel.open
}
// 事件广播型（background → content / UI）
export type Events = {
  'config:changed': UserConfig        // 设置页保存后广播，content 热更新
  'translation:status': { tabId: number; state: 'idle'|'translating'|'done'|'error' }
}
```

### 4.4 配置系统设计

- **存储分层**（v1.2 修订，评审 3.3-1）：`chrome.storage.sync` **单键上限 8KB、总限约 100KB** → 用户配置按**分区拆 key**（`userConfig:general` / `userConfig:services` / `...`，各分区一个 key，避免单键超限）；翻译缓存、术语库、规则覆盖一律落 **local**（无 8KB 限制）。P5 实施时 `storage.ts` 按「整包读、分区写」实现。
- **合并顺序**：`defaults.ts`（对象字面量，替代 566KB JSON；**版本化覆盖已 flatten 为生效值**，见 2.2-2）→ 命中站点规则 overlay → 用户配置 patch。提供 `deepMerge` 工具（数组整体覆盖语义）。
- **热更新**：设置页任何写入 → background 广播 `config:changed` → content 引擎无刷新生效（对齐原版"修改后立即生效"体验）。
- **迁移**：`ImportExport` 分区支持导入原版导出的 JSON（做键名映射转换，见附录 A）。

**MV3 硬约束清单**（v1.2 补，评审 3.3）

| # | 约束 | 对策 |
| --- | --- | --- |
| 1 | `sidePanel.open()` **必须用户手势**（SW 主动调用抛错） | 只从 popup 按钮/页面点击链路触发，不提供 SW 主动开启 |
| 2 | `captureVisibleTab` **限约 2 次/秒**且仅当前可见 tab | 圈选流程：页面画选区 → 发消息 background 截图 → 回传裁剪 → offscreen OCR；加节流与失败重试 |
| 3 | 页面 hook 脚本（canvas/XHR）必须 **MAIN world** | image/video-subtitle 注入脚本以 `world: 'MAIN'` 方式注入（WXT `world: 'MAIN'` 入口或 scripting API），否则 hook 无效 |
| 4 | 页面 UI 需 **Shadow DOM 隔离** | 悬浮球/划词弹窗/自绘字幕层用 closed ShadowRoot + 自带样式，避免站点 CSS 污染（译文 wrapper 仍在 light DOM 以便继承正文排版） |
| 5 | content script 动态加载 ESM | guard 保持单文件 IIFE（WXT 默认），引擎主体后续如需按需加载再做 spike |

### 4.5 翻译服务抽象

```ts
export interface TranslationService {
  id: string; name: string; kind: 'machine' | 'ai'
  needsKey: boolean
  batchLimit: number                    // 单次最大段落数
  translate(req: TranslateRequest): Promise<string[]>
}
// 适配器（Phase 2 实现）：
// bing.ts            → Edge translate 免费接口；**原版默认服务 id 为 `bing`**（`locales.json: translationServices.bing = 微软翻译`），
//                      `bing-free` 为 extends: bing 的免费变体 → 适配器同时注册两个 id，避免导入原版配置时找不到适配器（v1.2 补，评审 3.2-⑤）
// google.ts          → Google translate 免费接口（google-free 同 id 处理）
// openai-compatible  → 覆盖 OpenAI/DeepSeek/Gemini/Claude/自定义(模型+apiUrl+key+请求体模板+Temperature)
//                      含 aiBatch 增强模式: 分批/YAML结构化输出/完整性校验/局部重试/术语注入
// deeplx.ts          → 自建 DeepLX 端点（可选）
```

- **队列与节流**：每服务每秒最大请求数（默认 5，UI 显示值，原配置无对应键），超限排队（对齐原版「每秒最大请求数」设置）。
- **缓存**：`hash(service + from + to + text)` → local storage，命中直接返回（对齐「本地翻译缓存」）。
- **降级链**（v1.2 补）：免费通道连续失败时 bing → google → 自定义 API 依次降级并提示。

### 4.6 内容翻译引擎设计

1. **规则匹配**：URL → `builtin-rules.ts` 命中站点 overlay（selectors / excludeSelectors / injectedCss / 段落阈值）。
2. **段落识别**：`ParagraphWalker` — 规则 selectors 优先；未命中用启发式（`p, h1-h6, li, blockquote, td, pre` 等）+ 阈值过滤（最少字符数、最少词数，沿用原版默认 2 字符）；跳过 `translate=no`、`code`、`contenteditable`。
3. **翻译渲染**：`BilingualRenderer` — 原文后插入 wrapper `<span class="imt-target">`（译文在前/后可配）；主题系统 `translationTheme`（无/虚线/背景色/模糊学习模式…，CSS 变量驱动，对齐原版「译文显示样式」全部样式）。
4. **模式**：双语 / 仅译文 / 临时模糊；同语言相近加背景色（`sameLangTranslationTheme`）。
5. **交互层**（独立模块）：悬浮球（点击行为可配）、页面快捷面板、右键菜单联动、划词图标/小圆点 + 悬浮触发、圈选截图（`chrome.tabs.captureVisibleTab` → offscreen OCR）、鼠标悬停+触发键、输入框空格×3（200ms 判定窗口）。

## 7. 与原版的差异、风险与对策

### 7.1 功能差异声明

- 免费 google/bing 接口为**非官方通道**（原版同源），存在失效风险；对策：接口层抽象 + 失败自动降级提示 + 自定义 API 全量开放。
- 规则集无法 1:1 复刻 801 条：内置 top 50 站点精简规则 + 开发者设置本地编辑器补齐。
- 会员专属能力（智能上下文、AI 智能分句、云端 OCR 等）以「本地等价」或隐藏处理。

### 7.2 权限最小化（v1.2 修订，对比原版 manifest 实测）

| 权限 | 原版 | 本方案 |
| --- | --- | --- |
| storage / activeTab / contextMenus | ✅ | ✅ |
| **scripting** | ❌ **原版无此权限**（引擎注入靠 content_guard 动态 import，非 scripting API） | ❌ 不申请 |
| sidePanel / offscreen / commands | ✅ | ✅ |
| host_permissions | `<all_urls>` | `<all_urls>`（页面翻译必需） |
| webRequest | ✅（原版用于请求观察，改头实际由 DNR 完成） | ❌ 移除 |
| declarativeNetRequest* | ✅ | ✅ 双规则集：`rules-image.json`（防盗链，默认启用）+ `rules-api.json`（第三方通道改头，按需启用，v1.2 修订） |
| 遥测相关域名访问 | ✅ | ❌ 完全移除 |

### 7.3 主要风险

1. **内容引擎复杂度**（原版 4.3MB）：P3 只做主路径，样式主题逐步补齐。
2. **免费接口合规性**：仅个人学习使用，不做分发（与参考产物同等约束）。
3. **MV3 SW 生命周期**：翻译任务必须可中断恢复（缓存键已设计）；避免长连接。
